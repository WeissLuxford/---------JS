# Лист персонажа D&D 5e: памятка для работы

Интерактивный лист персонажа D&D 5e в стиле Baldur's Gate 3. Статичный сайт без сборки (vanilla JS, ES-модули), хостинг GitHub Pages, данные в Firebase (Firestore + Auth, бесплатный тариф Spark).

- Сайт: https://weissluxford.github.io/---------JS/
- Firebase-проект: `dnd-char-sheet-71645`
- Публикация: всё, что попадает в ветку `master`, через 1-2 минуты появляется на сайте.
- Рабочая ветка: создавай свою или используй ту, что задана в задаче, в `master` вливай только по просьбе владельца.

## Как запустить

```
python3 -m http.server 8765
```
Открыть http://localhost:8765/. Без доступа к Firebase сайт сам уходит в локальный режим (данные в localStorage).

Тесты: `node --test tests/unit/*.test.mjs` (без зависимостей), браузерные сценарии: `node tests/e2e/run.mjs` при запущенном сервере. Правила доступа: см. `docs/testing.md`.

Перед публикацией: юнит-тесты и e2e зелёные (публиковать только при «0 сценариев с ошибками», см. `docs/testing.md`), при новом файле в `js/` добавить его в `PRECACHE` в `sw.js` и поднять `VERSION` (иначе падает `sw.test.mjs`). Что сделано и что дальше: `docs/roadmap.md`.

## Правила кода (обязательно)

- Никаких комментариев в коде.
- Никаких длинных тире (символ U+2014) ни в коде, ни в текстах интерфейса.
- Интерфейс только на русском.
- Не создавать README-файлы.
- Стиль: двойные кавычки, отступ 2 пробела, точки с запятой ставятся, как в окружающем коде.
- Любые внешние данные проходят через `normalize()` из `js/rules.js`.
- Любая правка персонажа идёт через `mutate()` в `js/sheet.js` (в модулях `sheet-*.js` это `X.mutate()`).
- Всё, что попадает в `innerHTML`, экранируется через `esc()` из `js/ui.js`.
- Сохранение в облако только по путям полей (`saveChanges`), списки сущностей сливаются по `id`.
- Обучающие подсказки в разметке: `class="hint explain"` (прячутся переключателем в меню); новые пункты меню кладутся в свою группу в `menu()` (`js/sheet-dialogs.js`), см. `docs/ui-style.md`.
- Не трогать без просьбы владельца: размер портрета и вкладку «Персонаж», шапку листа; не заменять подписи голыми иконками.
- Любой сторонний бесплатный материал (иконки, шрифты, тексты, звуки, библиотеки), попавший на сайт, сразу вписывается в `CREDITS` в `js/credits.js` (окно «Благодарности» в футере главной).
- Тесты и эксперименты никогда не пишут в боевой Firestore: только эмулятор (`?emu` на localhost) или локальный режим.
