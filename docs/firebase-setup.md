# Firebase: что сделано и что осталось

Проект `dnd-char-sheet-71645`, тариф Spark (бесплатный).

## Сделано

- Firestore создан, работает.
- Authentication включён, провайдер Google включён.
- В Authorized domains добавлен `weissluxford.github.io`.
- В базе есть персонаж `kirion-thorndike` (создан до аккаунтов, без владельца).

## Осталось (по порядку)

1. Залить в `master` версию с аккаунтами (если ещё не залита) и подождать 1-2 минуты.
2. Скачать бэкап Кириона: открыть лист → Меню → "Скачать файл персонажа".
3. Войти на сайте через Google → на главной "Аккаунт" → "Скопировать ID".
4. Firestore Database → Rules: вставить текст из `firestore.rules`, заменить `ВСТАВЬ_СВОЙ_UID` на скопированный ID (одно место, в кавычках) → Publish. Правила начинают действовать примерно через минуту.
5. Обновить сайт. На главной появится раздел "Все остальные персонажи сайта", на карточке Кириона нажать "Без владельца: забрать себе".
6. Если в Sign-in method включён Anonymous, выключить его.
7. Проверка на телефоне: выйти и открыть ссылку на лист. Пока доступ по ссылке выключен, гость видит "Владелец закрыл доступ". После "Поделиться → Копировать" лист виден без кнопок правки.

## Проверка правил в консоли (Rules Playground)

- `get /characters/kirion-thorndike` без входа: Allow (у Кириона нет поля `visibility`, значит открыт по ссылке).
- `get /characters/kirion-thorndike/history/x` без входа: Deny.
- `update /characters/kirion-thorndike`, вход с провайдером `google.com`, чужой uid: Deny.

## Лимиты бесплатного тарифа

50 000 чтений, 20 000 записей, 20 000 удалений в день, 1 ГБ данных. Персонаж весит около 45 КБ (с портретом больше), сохранения идут по полям и весят сотни байт. Первым кончится лимит чтений: главная читает по документу на персонажа в списке.

## Если нужен платный тариф

Blaze с оплатой по факту, бесплатные лимиты в нём сохраняются. Нужен только если упрёмся в лимиты или захотим серверные функции (автоудаление, рассылки).
