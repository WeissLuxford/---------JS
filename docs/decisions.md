# Журнал решений

| Решение | Почему |
|---|---|
| Vanilla JS без сборки и фреймворка | сайт на GitHub Pages открывается сразу, правится из любого места; замеры показали, что скорости хватает (смена вкладки 13-42 мс при 4-кратном замедлении CPU) |
| Firebase Firestore на тарифе Spark | бесплатно, вживую синхронизирует несколько устройств, правила доступа на стороне сервера |
| Локальный режим на localStorage | сайт не ломается без интернета или если Firebase недоступен |
| Сохранение по полям, а не документом целиком | двое правят разные поля одновременно и ничего не теряют; сохранения весят сотни байт вместо ~200 КБ |
| Списки сливаются по `id` | правки разных предметов или заклинаний одного списка не затирают друг друга |
| Вход только через Google | пароли не теряются, запреты по аккаунту нельзя обойти режимом инкогнито; логин с паролем отклонён (нельзя восстановить пароль без почты) |
| Анонимного входа нет | иначе любой создаёт бесконечно новых "пользователей", и бан бессмыслен |
| Ссылка по умолчанию только для чтения, редакторы по приглашению | безопаснее, но сохраняет сценарий "скинул проверяющему, он поправил"; почты редакторов скрыты от остальных |
| Новые листы закрыты, пока ими не поделились | отозвать доступ можно в любой момент переключателем |
| Владелец сайта задаётся uid в правилах | нельзя подделать с клиента |
| Автоудаление неактивных аккаунтов не делаем | на Spark нет серверных задач по расписанию; персонаж ~45 КБ, в 1 ГБ помещаются тысячи; чистит владелец сайта вручную |
| Удаление аккаунта самим пользователем | приватность; удаляются профиль и все его листы с историей |
| История правок закрыта от посторонних | там видно, кто и когда правил; публично только имя и тип устройства последнего автора |
| Тип устройства без браузера и видеокарты | для банов по аккаунту отпечаток устройства не нужен, меньше личных данных |
| "Надгробие" `deleted/{id}` | чужой не сможет занять id удалённого листа по старой ссылке |
| Безопасный отказ при проверке версии правил | если проба не ответила, сайт считает правила строгими и перепроверяет в фоне |
| Нейтральный подзаголовок без "Baldur's Gate 3" | чтобы не выглядело как официальный продукт |
| Тексты заклинаний пишутся игроками или берутся из библиотеки SRD | официальные тексты PHB защищены; библиотека `data/spells-srd.json` это собственный перевод и сокращение SRD 5.1 (CC-BY-4.0), источник указан в окне библиотеки |
| Библиотека отдельным JSON и грузится по требованию | ~400 КБ не тормозят открытие листа |
| Стиль BG3 своими SVG и CSS | ассеты BG3 защищены авторским правом |
| Сервис-воркер "сначала сеть" для своих файлов | обновления с GitHub Pages видны сразу, без сети сайт открывается из кэша; SDK по версии в адресе, поэтому из кэша |
| Эффекты хранятся в листе, а не в устройстве | видны всем, кто открыл лист, и на всех устройствах; снимаются раундами, отдыхом или вместе с концентрацией |
| Старый проект (Math Quiz) в `old/` | главная занята листом, старое доступно по ссылке внизу |
